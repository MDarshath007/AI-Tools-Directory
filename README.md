# 🤖 AI Tools Directory

A React-based directory for discovering and exploring useful AI tools across different categories.

## ✨ Features

* 🔍 Search AI tools
* 🗂️ Browse tools by category
* 🔥 View trending/featured tools
* 📄 View detailed information about each tool
* 🔖 Bookmark favorite tools using LocalStorage
* 🌙 Light/Dark mode
* 📱 Responsive design

## 🛠️ Tech Stack

* React.js
* JavaScript
* Tailwind CSS
* React Router
* LocalStorage
* Font Awesome

## 📂 Project Structure

```text
src/
├── components/
├── pages/
├── data/
│   └── tools.js
├── assets/
└── App.jsx
```

## 🚀 Getting Started

```bash
git clone https://github.com/MDarshath007/AI-Tools-Directory.git
cd ai-tools-directory
npm install
npm run dev
```
